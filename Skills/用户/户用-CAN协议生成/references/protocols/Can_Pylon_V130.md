# PYLON LV V1.3

> 协议来源：`001-PYLON_CAN_LV_V1_3-2019_07_02.pdf`
> 项目参考实现：`assets/examples/Can_Pylon_V130.c`
> 协议类型：`A. 轮询发送型 + 局部接收`
> 参考级别：`灰名单`

---

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器（Tx）+ 局部 Rx |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 6 条报文轮询发送 |
| 接收机制 | `0x305` 心跳回复，`0x1001` 可选握手心跳 |
| 版本特征 | 派能低压 V1.3 变体，字段类型和品牌帧长度均与 EMS 版不同 |

---

## 2. 使用边界

- 适合作为 Pylon 低压 V1.3 差异点参考，而不是通用 Pylon 默认骨架。
- 可直接参考：
  - 6 帧 V1.3 轮询骨架
  - 有符号电流 / 电压字段
  - 2 字节品牌 `"PY"`
  - `0x1001` 接收框架
- 不可无条件外推：
  - 将其整体替代 `Pylon EMS`
  - 可选心跳逻辑
  - 删除 `0x373 / 0x379` 的做法

## 3. 报文结构

### 3.1 基础发送帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x359` | BMS→逆变器 | 保护与报警 |
| `0x351` | BMS→逆变器 | 充放电限值 |
| `0x355` | BMS→逆变器 | SOC / SOH |
| `0x356` | BMS→逆变器 | 模拟量（全有符号） |
| `0x35C` | BMS→逆变器 | BMS 控制请求 |
| `0x35E` | BMS→逆变器 | 品牌标识 |

### 3.2 条件发送帧

无。

### 3.3 接收 / 应答帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x305` | 逆变器→BMS | 心跳回复，可忽略处理 |
| `0x1001` | 逆变器→BMS | 可选握手心跳，上层需做超时控制 |

---

## 4. 关键差异与特殊处理

- 相比 EMS 版，仅发送 6 帧，不含 `0x373 / 0x379`。
- `ChargeI / DisChargeI / DisChargeV` 按 `int16_t` 处理。
- `0x356` 中 `VsumAvg / Current / BatteryTemp` 均按有符号量处理。
- 文档说明温度为 `0.1°C`；若项目旧代码存在 EMS 风格痕迹，生成时必须以目标协议文档为准。
- 品牌帧只发 `"PY"`，而不是 `"PYLON"`。
- `0x1001` 属于带风险的可选心跳逻辑，不应默认外推到普通协议。

---

## 5. 关键数据源

- `InverterData.ChargeI`
- `InverterData.DisChargeI`
- `InverterData.DisChargeV`
- `InverterData.VsumAvg`
- `InverterData.Current`
- `InverterData.BatteryTemp`
- 上层 5 分钟心跳超时能力（若实现 `0x1001`）
