> 协议来源：`003-Voltronic CAN 2021.08.16.pdf`

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS↔逆变器 |
| 帧格式 | 扩展帧 |
| 发送机制 | 由接收命令触发，不走常规轮询 |
| 接收机制 | 命令字解析后分派不同发送函数 |
| 版本特征 | 典型扩展帧命令分发型协议 |

---

## 2. 使用边界

- 适合作为“扩展帧命令分发 + 按命令应答”的经典正例。
- 可直接参考：
  - `ExtId` 组包方式
  - 命令字分发 `switch(Voltronic_cmd)`
  - 每个命令独立函数负责组帧和发送
  - `Pack_num` 逐包返回 pack 级数据
- 不可无条件外推：
  - 具体扩展 ID 计算方式
  - 每个命令对应的数据内容
  - `Pack_num` 上限、版本字节、厂家特有状态定义

---

## 3. 报文结构

### 3.1 基础发送帧

无。

### 3.2 条件发送帧

| CAN ID / 命令 | 条件 | 说明 |
|------|------|------|
| `0x0CF2xxxx` 系列 | 收到对应命令 | 不同命令返回不同 pack / 系统级数据 |

### 3.3 接收 / 应答帧

| 类型 | 方向 | 说明 |
|------|------|------|
| 扩展帧命令 | 逆变器→BMS | 触发不同发送函数 |

---

## 4. 关键差异与特殊处理

- 使用扩展帧 `CAN_ID_EXT`。
- 不走 `SendMsgIndex` 常规轮询。
- 每个命令对应一个独立函数。
- 同时包含整机级数据和 pack 级数据。

---

## 5. 关键数据源

- `PackData[Pack_num - 1].Vol[]`
- `PackData[Pack_num - 1].Temp[]`
- `PackData[Pack_num - 1].Current`
- `PackData[Pack_num - 1].Vsum`
- 其他按命令返回的 pack / system 数据
