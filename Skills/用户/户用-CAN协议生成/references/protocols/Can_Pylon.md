# PYLON EMS

> 协议来源：`001-PYLON_CAN_Inverter_EMS.pdf`
> 项目参考实现：`assets/examples/Can_Pylon.c`
> 协议类型：`A. 轮询发送型`
> 参考级别：`白名单`

---

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器（Tx 为主） |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 8 条报文轮询发送 |
| 接收机制 | 可收到标准帧 / 扩展帧范围内消息，默认仅占位 |
| 版本特征 | Pylon 经典 EMS 版骨架，含极值帧和总容量帧 |

---

## 2. 使用边界

- 适合作为 A 类基础轮询发送型协议的经典正例。
- 可直接参考：
  - 8 帧 `SendMsgIndex` 轮询骨架
  - 保护 / 告警双字节组织
  - `0x373` 极值帧
  - `0x379` 总容量帧
  - 品牌字符 `"PYLON"` 的固定写法
- 不可无条件外推：
  - 接收范围占位处理
  - 品牌字符串长度
  - 与低压 V1.3 版存在明显版本差异的字段定义

## 3. 报文结构

### 3.1 基础发送帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x359` | BMS→逆变器 | 保护与报警 |
| `0x351` | BMS→逆变器 | 充放电限值 |
| `0x355` | BMS→逆变器 | SOC / SOH |
| `0x356` | BMS→逆变器 | 模拟量（电压 / 电流 / 温度） |
| `0x35C` | BMS→逆变器 | BMS 控制请求 |
| `0x35E` | BMS→逆变器 | 品牌标识 |
| `0x373` | BMS→逆变器 | 单芯极值 |
| `0x379` | BMS→逆变器 | 装机总容量 |

### 3.2 条件发送帧

无。

### 3.3 接收 / 应答帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x305~0x3FF` | 逆变器→BMS | 标准帧接收范围，占位处理 |
| `0x4000000~0x5200000` | 逆变器→BMS | 扩展帧接收范围，占位处理 |

## 4. 关键差异与特殊处理

- `BatteryTemp` 发送前减 `2730`，即 `0.1K -> 0.1°C`。
- `VsumAvg` 发送单位为 `0.01V`，项目实现中直接 `/10`。
- `Current` 发送单位为 `0.1A`，项目实现中直接 `/10`。
- `Tmin / Tmax` 在 `0x373` 中按 `1K` 发送，项目实现中直接 `/10`。
- `FccAll` 在 `0x379` 中按 Ah 发送，项目实现中直接 `/100`。
- 与 `Pylon_V130` 相比，本版没有 `0x1001` 心跳逻辑，并保留 `0x373 / 0x379`。

## 6. 生成提示

- 当目标协议属于常规 Pylon / Pylon-like 轮询型时，可优先参考本文件的基础骨架。
- 若目标协议同样定义极值帧和总容量帧，不应只生成 6 帧，应继续补 `0x373`、`0x379`。
- 若目标协议属于低压 V1.3 变体，不应直接套用本文件，应转去比较 `Can_Pylon_V130.md` 的版本差异。
- 若只借风格，优先借骨架、字段直取和容量拆字节写法，不要无条件借接收范围占位逻辑。
