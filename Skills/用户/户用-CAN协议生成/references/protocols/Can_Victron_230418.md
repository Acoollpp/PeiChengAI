# VICTRON 2023.04.18

> 协议来源：`010-Victron CAN_Freedom_Won 2023.04.18.docx`
> 项目参考实现：`assets/examples/Can_Victron_230418.c`
> 协议类型：`A/D 之间的系统级轮询扩展型`
> 参考级别：`白名单`

---

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器 |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 基础轮询帧后继续发送系统级扩展帧 |
| 接收机制 | 无明显专用接收状态机 |
| 版本特征 | 地址 ASCII 扩展明显，状态位按字节分组 |

---

## 2. 使用边界

- 适合作为“系统级轮询扩展”和“地址 ASCII 编码”的经典正例。
- 可直接参考：
  - `0x35A` 保护 / 告警按字节分组输出
  - `0x374~0x377` 地址字段 ASCII 编码与发送
  - 基础轮询帧后继续发送系统级扩展帧
  - 固定 8 字节品牌数组发送
- 不可无条件外推：
  - 具体状态位定义
  - 地址字段位数与组合方式
  - 特定品牌名和字段顺序

---

## 3. 报文结构

### 3.1 基础发送帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x351` | BMS→逆变器 | 充放电限值 |
| `0x355` | BMS→逆变器 | SOC / SOH |
| `0x356` | BMS→逆变器 | 电压、电流、温度 |
| `0x35E` | BMS→逆变器 | 品牌 ASCII |

### 3.2 条件发送帧

| CAN ID | 条件 | 说明 |
|------|------|------|
| `0x35A` | 协议定义 | 保护 / 告警按字节分组 |
| `0x374~0x377` | 协议定义 | 地址 / 系统 ASCII 扩展 |

### 3.3 接收 / 应答帧

无。

---

## 4. 关键差异与特殊处理

- 与 CanadianSolar 相比，本文件的系统级扩展层更集中。
- 保护 / 告警不是压成 16 位，而是按多个 `uint8_t` 分组输出。
- `VE_name[8]` 这类固定发送缓存，适合品牌名长度固定的协议。

---

## 5. 关键数据源

- 多字节状态位输出来源
- 地址 ASCII 编码字段
- 固定品牌字符串缓存
