# GROWATT LV V1.09

> 协议来源：`002-Growatt CAN LV V1.09-2020.10.22.pdf`
> 项目参考实现：`assets/examples/Can_Growatt_V109.c`
> 协议类型：`A. 轮询发送型 + 局部请求应答接收`
> 参考级别：`白名单`

---

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器（Tx）+ 局部 Rx |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 8 条基础帧轮询发送，条件满足时追加 4 条单体帧 |
| 接收机制 | 心跳、时间同步、产品码查询 |
| 版本特征 | 基础轮询 + 功能帧扩展 + 少量请求应答 |

---

## 2. 使用边界

- 适合作为 Growatt 同类协议和“功能帧可补齐型”协议的正例参考。
- 可直接参考：
  - `switch(SendMsgIndex)` 轮询发送骨架
  - 状态保护 / 告警位整理函数
  - `DeltaV`、极值地址、温度地址直取
  - `0x315~0x318` 单体电压分帧发送
- 不可无条件外推：
  - `IsCommBreak()` 心跳中断检测
  - `0x324` 产品码分包响应
  - `0x211` RTC 写入
  - 依赖 `WarningPara`、`Pack_Cells_Num`、`Product_Code`、`LocalAddr` 的工程化逻辑

## 3. 报文结构

### 3.1 基础发送帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x311` | BMS→逆变器 | 充电电压、电流、放电电流、状态字 |
| `0x312` | BMS→逆变器 | 保护、告警、包数 |
| `0x313` | BMS→逆变器 | 总压、电流、平均温度、SOC / SOH |
| `0x314` | BMS→逆变器 | 剩余容量、满充容量、压差、循环次数 |
| `0x319` | BMS→逆变器 | 请求标志、最高 / 最低单体电压、极值地址、故障 ID |
| `0x320` | BMS→逆变器 | 厂商标识 / 版本占位 |
| `0x322` | BMS→逆变器 | 最高 / 最低温度、温度地址、系统最大 / 最小 SOC |
| `0x323` | BMS→逆变器 | 扩展保护 / 告警信息 |

### 3.2 条件发送帧

| CAN ID | 条件 | 说明 |
|------|------|------|
| `0x315` | `PackNum == 1` 后继续发送 | 单体 0~3 电压 |
| `0x316` | 同上 | 单体 4~7 电压 |
| `0x317` | 同上 | 单体 8~11 电压 |
| `0x318` | 同上 | 单体 12~15 电压 |

### 3.3 接收 / 应答帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x301` | 逆变器→BMS | 心跳 |
| `0x211` | 逆变器→BMS | 日期时间同步 |
| `0x212` | 逆变器→BMS | 产品码查询请求 |
| `0x324` | BMS→逆变器 | 产品码分包响应 |

## 4. 关键差异与特殊处理

- `BatteryTemp / Tmax / Tmin` 内部单位 `0.1K`，发送前统一减 `2730`。
- `Vsum` 发送单位为 `0.01V`，项目实现中直接 `/10`。
- `Current` 项目实现中直接 `/10` 后按 16 位发送。
- `DeltaV` 直接使用 `InverterData.DeltaV`。
- 本协议的关键特征不是“多帧”，而是“在数据源明确时应继续补齐功能帧”。

---

## 5. 关键数据源

- `InverterData.DeltaV`
- `InverterData.GmaxAddr`
- `InverterData.GminAddr`
- `InverterData.TmaxAddr`
- `InverterData.TminAddr`
- `PackData[0].Vol[0..15]`

## 6. 生成提示

- 当目标协议与 Growatt V1.09 同类，且协议文档同样定义了单体电压分帧时，不应只生成基础帧，应继续补 `0x315~0x318`。
- 若只是借风格，可借鉴轮询骨架与字段组织方式。
- 若参考逻辑，必须先确认目标协议的帧号、单位、发送条件与本协议一致。
- 对依赖接收触发或产品码分包的部分，若数据源或触发条件不完整，应保留 `TODO[未实现]`。
