# AISWEI HV V1.0

> 协议来源：`062-AISWEI CAN HV V1.0.pdf`
> 项目参考实现：`assets/examples/Can_Aiswei_V100.c`
> 协议类型：`A. 轮询发送型 + 局部系统级扩展帧`
> 参考级别：`白名单`

---

## 1. 协议概览

| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器 |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 6 条基础轮询 + 局部扩展补充帧 |
| 接收机制 | 无明显专用接收状态机 |
| 版本特征 | 基础轮询骨架清晰，字段直取较多 |

---

## 2. 使用边界

- 适合作为“基础轮询发送骨架”的经典正例。
- 可直接参考：
  - `switch(SendMsgIndex)` 轮询发送框架
  - 保护 / 告警位合成函数
  - `0x359/0x351/0x355/0x356/0x35C/0x35E` 的基础发送组
  - `uint8_t` 映射 2 字节槽位时“低字节写值、高字节写 0”的写法
  - 数值型地址字段的直接发送
- 不可无条件外推：
  - `0x374/0x375` 系统级补充帧
  - 品牌字符串内容
  - 未在协议中定义的保留字节含义

---

## 3. 报文结构

### 3.1 基础发送帧

| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x359` | BMS→逆变器 | 保护、告警、包数、品牌标识尾字节 |
| `0x351` | BMS→逆变器 | 充电电压、电流、放电电流、放电截止电压 |
| `0x355` | BMS→逆变器 | SOC / SOH |
| `0x356` | BMS→逆变器 | 总压、电流、温度 |
| `0x35C` | BMS→逆变器 | 控制请求 |
| `0x35E` | BMS→逆变器 | 品牌 ASCII |

### 3.2 条件发送帧

| CAN ID | 条件 | 说明 |
|------|------|------|
| `0x374` | 协议定义 | 地址 / 系统级扩展信息 |
| `0x375` | 协议定义 | 地址 / 系统级扩展信息 |

### 3.3 接收 / 应答帧

无。

---

## 4. 关键差异与特殊处理

- `Vsum` 发送单位为 `0.01V`，项目实现中直接 `/10`。
- `Current` 发送单位为 `0.1A`，项目实现中直接 `/10`。
- `BatteryTemp` 内部单位 `0.1K`，发送前减 `2730`。
- 本文件的核心价值在于“简单、稳定、直取字段”，适合做基础轮询模板。

## 6. 生成提示

- 若目标协议只是常规轮询发送，不需要优先套用更复杂的 CanadianSolar / Growatt 骨架，可优先参考本文件。
- 若目标协议存在系统级补充帧，可仅局部参考本文件的后续扩展，不要把所有补充帧默认外推到新协议。
- 若字段本身就是现成参数，可优先参考本文件“直接取值，不先推导”的写法。
