# 协议说明模板

用于给 `references/protocols/Can_Xxx.md` 建立统一格式。目标不是逐字节搬运原始文档，而是保留“足以指导代码生成”的结构化信息。

---

## 文件头

```md
# 协议名

> 协议来源：`原始 PDF / Word 文件名`
> 项目参考实现：`assets/examples/Can_Xxx.c`
> 协议类型：`A / B / C / D 分类`
> 参考级别：`白名单 / 灰名单 / 黑名单`
```

---

## 1. 协议概览

建议包含：
- 通信方向
- 帧格式
- 发送机制
- 接收机制
- 版本特征

表格模板：

```md
| 项目 | 内容 |
|------|------|
| 通信方向 | BMS→逆变器 |
| 帧格式 | 标准帧，DLC = 8 |
| 发送机制 | 8 条报文轮询发送 |
| 接收机制 | 无明显专用接收状态机 |
| 版本特征 | 基础轮询骨架清晰 |
```

---

## 2. 使用边界

建议说明：
- 适合作为什么类型协议的参考
- 可直接参考哪些部分
- 不可无条件外推哪些部分

模板：

```md
- 适合作为 A 类基础轮询发送型协议的参考。
- 可直接参考：
  - 轮询骨架
  - 字段组织方式
- 不可无条件外推：
  - 接收状态机
  - 客户特化逻辑
```

---

## 3. 报文结构

### 3.1 基础发送帧

```md
| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x351` | BMS→逆变器 | 充放电限值 |
```

### 3.2 条件发送帧

```md
| CAN ID | 条件 | 说明 |
|------|------|------|
| `0x374` | 协议定义 | 地址扩展信息 |
```

### 3.3 接收 / 应答帧

```md
| CAN ID | 方向 | 说明 |
|------|------|------|
| `0x305` | 逆变器→BMS | 心跳 |
```

说明：
- 若某一类不存在，可写“无”。
- 报文表只保留结构级信息，不在这里展开每个字节定义。
