# 协议枚举索引

本索引用于给协议移植提供当前工程真实存在的枚举名和枚举值。

来源：
- `User/Bms_Config.h`

使用规则：
- 先用这里确认当前工程已经占用的枚举名和值
- 若用户给的新协议能映射到这里已有枚举，就直接沿用，不要重造名字
- 若当前工程里找不到该协议对应的正式 `.c` 文件，也找不到可参考的同族已挂接实现，就必须提醒用户提供目标枚举值
- 在用户没有明确给出枚举值前，不要自行猜测新增枚举值
- 真正落地修改前，仍要回查最新的 `User/Bms_Config.h`，以防索引过期
