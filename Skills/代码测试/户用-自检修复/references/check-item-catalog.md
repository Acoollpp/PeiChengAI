# Check Item Catalog

Use this file only as the item index. Keep the actual per-item status and repair scheme in `references/items/`.

## Usage Rule

- Find the failed checklist id here.
- Open the linked item file.
- If the item file says `状态: 暂未添加`, do not guess the repair scheme.
- When the user gives a scheme for one item, update only that item file.
