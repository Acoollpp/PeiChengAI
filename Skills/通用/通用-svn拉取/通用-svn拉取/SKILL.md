# 通用-svn拉取

## 概述

这个 skill 用于把指定 `SVN` 仓库内容稳定拉取到本地目录。
重点不是只执行 `svn checkout/export`，而是确保文件真实落盘，并在目标路径包含中文或深层目录时优先规避命令行 `svn` 的路径兼容问题。

## 适用场景

- 用户要求“拉取 SVN 项目”
- 用户要求“下载某个 revision 到本地”
- 用户提供 `SVN URL + 版本号 + 目标路径`，希望把工程导出到本地
- 用户要求 `checkout` 或 `export` 某个 SVN 目录
- 用户反馈命令行 `svn` 显示成功，但目标目录实际没有文件

不适用于：

- 只做两个版本之间的代码审查
- 只查看 `svn log`、`svn diff`，不需要本地落盘
- 只处理 `git` 仓库

## 必须先收集的信息

开始执行前，至少确认以下信息：

1. `SVN` 仓库地址
2. 目标版本号（`revision`）
3. 本地目标路径

如果用户没有明确说要 `checkout` 还是 `export`，默认优先按“导出到本地可见目录”处理。
除非用户明确要求保留工作副本元数据，否则优先使用 `export` 思路，而不是保留 `.svn` 的工作副本。

## 执行流程

严格按下面顺序执行，不要直接跳到拉取动作：

### 1. 先检查环境与目标目录

- 确认本机 `svn` 命令可用
- 确认目标目录是否存在
- 如果目标目录已存在，先确认是否为空目录，或是否允许覆盖
- 如果用户给的是中文路径或较深路径，提前把它标记为高风险目标路径

### 2. 先验证仓库可访问

优先做最小验证：

- `svn list` 验证仓库地址可访问
- 确认 `revision` 存在且可读取

如果连 `svn list` 或单文件读取都失败，不要继续做导出，先说明阻塞点。

### 3. 默认使用“短英文路径中转”策略

当目标路径包含中文、空格较多、或目录层级较深时，不要直接把命令行 `svn` 导出到用户目标目录。

优先采用下面流程：

1. 在磁盘根目录或短英文路径创建中转目录
2. 先把指定 `revision` 导出到中转目录
3. 导出完成后，必须实际检查关键目录和关键文件是否存在
4. 再把中转目录内容复制到用户目标目录
5. 如用户不需要中转缓存，最后删除中转目录

推荐中转路径示例：

- `E:/svn_export_tmp`
- `E:/svn_39634_full`

### 4. 直接导出只在低风险路径下使用

只有在以下条件同时满足时，才优先考虑直接导出到用户目标目录：

- 目标路径为短英文路径
- 目录层级不深
- 用户明确要求保留在该目录直接落盘

如果直接导出后目录为空，不要只相信 `svn` 的成功输出，必须立即回退到“短英文路径中转”方案。

### 5. 验证必须基于真实文件系统

执行完拉取后，必须做二次验证，至少确认：

- 顶层目录是否真实存在
- 核心子目录是否真实存在
- 至少一个关键文件是否真实存在

不要只依据：

- `svn` 命令返回码
- 命令行中的 `A ...`
- `Checked out revision ...`
- `Exported revision ...`

如果文件系统复核结果和命令输出不一致，以文件系统复核为准。

### 6. 异常排查优先级

如果出现“命令看似成功，但目录为空”的情况，按下面顺序排查：

1. 先手工在目标目录创建一个普通探针文件，确认该目录本身可写
2. 再做单文件 `svn export` 实验，确认是否连单文件都失败
3. 判断是否为中文路径问题
4. 判断是否为深层路径问题
5. 用短英文路径做对照实验

如果短英文路径成功、中文路径失败，应明确告诉用户：

- 仓库访问正常
- `svn` 命令在当前环境下对中文目标路径兼容异常
- 已切换为短英文路径中转再复制的稳定方案

## 输出要求

完成后必须明确回告：

- 拉取的仓库地址
- 拉取的 `revision`
- 最终真实落盘路径
- 是否使用了中转目录
- 中转目录是否已删除

不要只说“已经下载完成”，必须给出可定位的实际路径。

## 推荐回复模板

如果用户信息不完整，可先提示：

```text
我会帮你把 SVN 项目拉取到本地。请提供仓库地址、目标版本号和本地目标路径；如果没有特别要求，我会优先用稳定的导出方式，必要时先导出到短英文中转目录，再复制到你的目标位置。
```

如果识别到中文路径风险，可在执行前说明：

```text
你给的目标路径包含中文目录。命令行 svn 在当前环境下可能出现“显示成功但实际未落盘”的情况，我会优先走短英文路径中转，再复制到你的目标目录，确保文件真实可见。
```

## 质量要求

- 以“真实落盘”为第一目标，不以命令返回成功为完成标准
- 优先稳定性，避免在中文路径上反复直接尝试
- 每次完成后都做文件系统复核
- 如果用了中转目录，除非用户要求保留，否则任务结束前清理
