# PeiChengAI

PeiChengAI 是 AI Agent 服务和 Codex Skill 能力库的统一仓库。

- `Agent/` 存放各种可运行的 Agent 服务。每个服务都应维护自己的 `README.md`，详细说明启动方式、接口、配置和测试方法。
- `Skills/` 存放可复用的 Skill。根 README 负责维护 Skill 总览，方便按业务场景查找能力。

## Agent 服务

| 服务 | 路径 | 作用 |
| --- | --- | --- |
| Codex 代码审查 Web 服务 | `Agent/Code_review` | 基于 FastAPI 提供 SVN 版本差异审查入口，后台调用 Codex 与代码审查 Skill 生成 Markdown 审查报告。 |

详细说明请进入对应目录查看，例如 `Agent/Code_review/README.md`。

## 维护约定

- 新增 Agent 服务时，放入 `Agent/<服务名>/`，并在服务目录维护独立 `README.md`。
- 根 README 只保留 Agent 服务索引，不展开服务的安装、启动、接口和测试细节。
- 新增 Skill 时，放入 `Skills/<分类>/<Skill名称>/`，并确保存在清晰的 `SKILL.md`。
- 根 README 的 Skill 清单应随 `Skills/` 目录变化同步更新。
- 压缩包只作为临时交付物使用，解压确认后删除，仓库中保留可直接阅读和调用的目录结构。
