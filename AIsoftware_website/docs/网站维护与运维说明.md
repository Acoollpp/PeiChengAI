# 网站维护与运维说明

## 正式发布目录

软件部 AI 应用展示网站的正式发布目录为：

```text
/Users/chenghao/Sites/software_website_frontend
```

仓库中的维护源目录为：

```text
/Users/chenghao/PeiChengAI/AIsoftware_website/frontend
```

发布时执行 `sync-and-restart-service.sh`，脚本会将仓库前端目录同步到正式发布目录，并刷新本机 Nginx 后台服务。

## Nginx

网站通过本机 Nginx 静态服务提供访问，当前端口为 `5174`。配置模板位于 `ops/nginx-software-website.conf`，健康检查入口为 `/healthz`。

日常检查可执行：

```bash
./check-website-health.sh
```

脚本会检查 Nginx 是否监听 `5174` 端口，并验证首页、平台页、Skills 页和健康检查接口是否可访问。

## 单点风险

当前站点运行在本机静态服务上，存在机器关机、网络变化、Nginx 服务异常或发布目录被误改的单点风险。更新前建议保留 Git 基线，更新后及时运行健康检查。

## Git 基线

每次较大内容更新后，建议先在仓库内同步 `AIsoftware_website/frontend`，再运行测试并提交 Git。大安装包、临时日志、备份包和系统缓存文件不进入 Git。

## 平台地址集中维护

平台访问地址统一维护在：

```text
frontend/data/platform-urls.js
```

新增或调整 API 管理平台、Openclaw、代码审查看板、AI 应用统计管理平台、GPT 账号管理平台等入口时，优先修改该文件，页面通过统一注册表自动读取地址。
