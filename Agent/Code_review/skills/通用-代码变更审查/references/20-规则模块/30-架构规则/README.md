# 架构规则

架构规则用于判断模块边界、依赖关系、团队规范、协议字段、数据落点和状态链路风险。

| 文件 | 作用 |
|---|---|
| `10-模块边界规则.md` | 判断是否破坏模块职责和调用边界 |
| `20-不合理依赖规则.md` | 判断是否引入不合理依赖或反向依赖 |
| `30-团队规范符合性规则.md` | 判断是否违反团队约定和项目结构规范 |
| `40-协议字段一致性规则.md` | 判断协议字段上下游是否一致 |
| `50-数据落点与截断规则.md` | 判断字段落点、长度截断、同字段覆盖 |
| `60-状态链路一致性规则.md` | 判断状态生成、状态消费和输出链路是否一致 |

新增架构类规则时，优先追加到已有文件；无法承载时，从 `70-xxx规则.md` 开始新增，并更新本 README。
