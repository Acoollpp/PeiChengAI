# 状态链路一致性规则

## 适用场景

- 新增或修改状态字、告警位、保护位、干接点状态、LED/蜂鸣器/继电器输出。

## 判定依据

- 状态生成位置
- 状态消费位置
- 通信上报位置
- 硬件输出控制位置
- 初始化和默认值

## 审查方法

- 检查状态是否被正确生成。
- 检查状态是否被正确消费或上报。
- 检查原状态链路是否被替换但未完整迁移。
- 检查默认值和掉电恢复是否符合预期。

## 输出要求

状态链路风险应说明：

- 状态来源
- 中间传递路径
- 最终输出或上报位置
- 需要实机验证的场景

## 不适用场景

- 不影响外部输出、通信上报或业务判断的内部临时状态。
