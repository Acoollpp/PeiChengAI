# AI规则

AI规则用于辅助理解差异、推理风险、补充边界条件、判断性能影响和提出可读性建议。

| 文件 | 作用 |
|---|---|
| `10-代码差异解释规则.md` | 解释 diff 的功能意图和影响范围 |
| `20-潜在Bug识别规则.md` | 识别潜在逻辑缺陷和异常行为 |
| `30-边界条件审查规则.md` | 补充边界输入、长度、索引、状态边界 |
| `40-性能风险审查规则.md` | 判断实时性、Flash、通信和主循环性能风险 |
| `50-可读性建议规则.md` | 输出必要的可读性、可维护性建议 |

新增 AI 类规则时，优先追加到已有文件；无法承载时，从 `60-xxx规则.md` 开始新增，并更新本 README。
