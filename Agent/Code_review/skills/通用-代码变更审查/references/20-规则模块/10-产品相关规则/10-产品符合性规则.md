# 产品符合性规则

## 适用场景

- 变更影响产品功能、默认参数、客户定制项、告警行为或通信表现。
- 变更涉及需求表、规格书、调试报告或客户确认项。

## 判定依据

- 需求文档、检查表、自检表、调试报告
- 变更文件和关键代码路径
- 默认配置、宏定义、状态字、协议字段

## 审查方法

- 判断代码行为是否与需求描述一致。
- 对默认值变化、功能开关变化、告警屏蔽、状态输出变化进行产品影响分析。
- 不能把产品行为变化只写成“代码修改”，必须说明对用户场景的影响。

## 输出要求

报告中应说明：

- 变更对应的产品功能
- 是否有明确需求依据
- 是否需要产品确认或实机验证

## 不适用场景

- 纯格式化、注释或无行为影响的修改。
