# 检查表审查规则

## 适用场景

- 用户提供检查表、自检表、Excel 表格或截图。
- 变更清单中包含 `doc/`、`.xlsx`、`.xls`、`.png` 等检查材料。

## 判定依据

- 检查表正文
- 检查表点名文件
- 检查表中的风险等级、概率、影响程度说明
- 检查表图片中的规则说明

## 审查方法

- 必须读取检查表正文和可提取的图片内容。
- 检查表点名的文件必须进入重点审查范围。
- 报告中必须说明检查表相关条目是否被覆盖。
- 如果检查表要求与代码实现不一致，必须列为风险。

## 输出要求

在报告中写明：

- 已读取的检查表名称
- 与本次变更直接相关的条目
- 已确认符合、已确认不符合、仍需验证的条目

## 不适用场景

- 没有检查表或检查材料时，不强行生成检查表结论。
