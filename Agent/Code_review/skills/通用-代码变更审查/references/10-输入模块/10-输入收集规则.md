# 输入收集规则

## 必填输入

执行代码变更审查前，必须确认：

- SVN 项目路径或本地工作副本路径
- 旧版本号
- 新版本号
- 报告输出路径

如果缺少其中任一项，只补问缺失项，不重复询问已给出的信息。

## 默认输出路径

如果用户未指定输出路径，默认使用当前工作目录，并按“项目路径最后一级名称 + 审查报告.md”命名。

示例：

```text
SST22-1404-T审查报告.md
```

## 输入校验

- SVN 路径必须保留原始字符串，不要擅自修改大小写、分支名或项目名。
- 版本号统一按 `r旧版本 -> r新版本` 记录。
- 如果用户写成 `r25576r29303` 等连写形式，应拆分为旧版本 `r25576`、新版本 `r29303` 并向用户确认。
- 如果用户给的是本地路径，应先判断是否为 SVN 工作副本。

## 输出要求

报告第一部分必须写清：

- 项目路径
- 旧版本号
- 新版本号
- 审查方式
- 报告输出路径
