## 三、审查问题

### CR-001 [高] 休眠状态仍可打开充电 MOS

**所属审查项：** DS-03 · 状态机审核
**规则章节：** 休眠状态与 MOS 输出约束
**规则 ID：** DS03-SLEEP-001

**涉及文件及行号：**

| 文件 | 行号 | 位置说明 |
|------|------|----------|
| `source/control.c` | 88 | `ApplyChargeMos` 中的充电 MOS 输出动作 |
| `source/state.c` | 120-135 | 休眠状态的守卫条件 |

**问题描述：** 休眠状态分支未阻断充电 MOS 开启路径，满足远程唤醒条件时会绕过休眠保护。
**影响风险：** 设备休眠后仍可能打开充电 MOS，违反休眠状态输出约束。
**整改建议：** 在最终输出前统一校验休眠状态并保持充电 MOS 关闭。

---

### CR-004 [中] 故障恢复路径缺少状态一致性校验

**所属审查项：** DS-01 · 变更点审查；DS-03 · 状态机审核
**规则章节：** 状态恢复检查

**涉及文件及行号：**

| 文件 | 行号 | 位置说明 |
|------|------|----------|
| `source/state.c` | 166-174 | 故障恢复后的状态切换入口 |

**问题描述：** 故障清除后直接切换运行状态，未校验受控输出与目标状态是否一致。
**影响风险：** 状态恢复瞬间可能保留与目标状态不一致的输出。
**整改建议：** 状态切换前统一执行输出一致性校验。
