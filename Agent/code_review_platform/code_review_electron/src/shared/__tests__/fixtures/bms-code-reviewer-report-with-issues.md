## 三、审查问题

### P01 [高风险] 休眠状态仍可打开充电 MOS

**所属审查项：** DS-03 · 状态机审核
**规则章节：** 休眠状态与 MOS 输出约束
**规则 ID：** DS03-SLEEP-001

**涉及文件及行号：**

| 文件 | 行号 | 位置说明 |
|------|------|----------|
| `source/control.c` | 88 | `ApplyChargeMos` 中的充电 MOS 输出动作 |
| `source/state.c` | 120-135 | 休眠状态的守卫条件 |

**问题描述：** 休眠状态分支未阻断充电 MOS 开启路径，满足远程唤醒条件时会绕过休眠保护。
**影响风险：** 设备休眠后仍可能打开充电 MOS，违反休眠状态输出约束。
**整改建议：** 在最终输出前统一校验休眠状态并保持充电 MOS 关闭。

---

### P02 [建议] 补充休眠恢复路径的往返测试

**所属审查项：** DS-01 · 变更点审查；DS-03 · 状态机审核
**规则章节：** 需求验收场景；状态恢复测试

**涉及文件及行号：**

| 文件 | 行号 | 位置说明 |
|------|------|----------|
| `tests/state_test.c` | 42 | 现有休眠恢复测试入口 |

**问题描述：** 当前测试只覆盖进入休眠，未覆盖故障清除后恢复并再次进入休眠的往返路径。
**影响风险：** 后续状态恢复修改缺少自动回归证据。
**整改建议：** 增加休眠、恢复、再次休眠的往返测试。
