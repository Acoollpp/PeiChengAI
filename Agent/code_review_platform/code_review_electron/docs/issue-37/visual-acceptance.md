## 生成截图

首次运行时安装 Playwright Chromium：

```bash
npx playwright install chromium
```

随后执行：

```bash
npm run capture:workbench
```

脚本会自行启动隔离的 Vite 预览，不访问生产 preload、服务端、SVN、Codex 或本地材料。截图输出到 `docs/issue-37/screenshots/`。
