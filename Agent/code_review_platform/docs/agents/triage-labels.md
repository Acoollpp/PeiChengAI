# 分类标签

工程技能使用五种固定的分类角色。本文件将这些标准角色映射到本仓库实际使用的中文标签。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分类` | 维护者需要评估和分类该问题 |
| `needs-info` | `待补充信息` | 正在等待报告者补充必要信息 |
| `ready-for-agent` | `待智能体处理` | 信息已经完整，可以交给智能体处理 |
| `ready-for-human` | `待人工处理` | 需要由人工判断或实施 |
| `wontfix` | `不计划处理` | 当前不准备继续处理 |

当技能提到某个标准角色时，必须使用本表中对应的中文标签。

如果以后调整 GitHub 中的标签名称，应同步修改本表右侧的中文标签，但不要修改左侧的标准角色。
