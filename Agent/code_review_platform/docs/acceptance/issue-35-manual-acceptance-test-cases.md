## 2. 验收目标

本轮验收确认以下事实：

1. 报告中心、报告摘要和任务详情读取真实服务端数据，生产入口不读取预览 fixture。
2. 新版 `bms-code-reviewer` 有问题、零问题及真实 `CR-*` 变体均正确展示。
3. 多审查项、最高严重度、问题数量和完成时间均来自真实任务，不能伪造。
4. 1.x 缺少新字段的历史任务仍可查看，不抛错、不伪造审查项或零问题。
5. Markdown、PDF、图片、逐问题反馈草稿、正式提交和反馈版 PDF 链路保持可用。
6. 新旧任务混合列表、权限和部门过滤不发生回归。
7. 列表失败、单报告失败或解析失败仅局部降级，不阻断工作台主流程。
