# BOM表改制检查测试方案

更新时间：2026-07-29

## 测试目标

验证 `BOM表改制检查` 平台从上传压缩包到生成报告的完整链路可用，重点确认：

- 压缩包上传、解压和存储正确。
- 替代料汇总表可在提交页按需上传，并作为全平台最新版本复用。
- 未上传且平台无历史最新替代料汇总表时，任务在启动前被拒绝。
- 网页上传或平台保存的替代料汇总表优先于项目压缩包内公司物料表。
- 固定分类文件夹识别正确。
- 改制表通过“项目号 + 版本号”匹配改制前 BOM 和改制后 BOM。
- 项目压缩包只包含更新后 BOM，且页面上传或平台已保存替代料汇总表时，进入“只审查替代料是否合规”模式。
- 项目压缩包额外包含扁平 `更新后BOM/` 或 `更新BOM/` 时，能生成 `替代料组齐全差异.xlsx`，按项目号分 sheet 只列缺失物料。
- 项目压缩包包含 `更新BOM/日期文件夹/BOM文件` 时，能按日期生成 `BOM表改制检查报告-日期.xlsx`，每个 BOM 一个 sheet；没有关键物料/无关键物料关键词的 BOM 输出 `跳过`。
- 后端通过 Codex 调用 `$bom-change-check` skill，而不是直接绕过 Codex 调脚本。
- Codex 调用 skill 内固定批处理脚本，不重新生成临时脚本，不手工逐个 Excel 分析。
- 输出报告结构、列顺序、异常标黄和 summary 统计符合规则。
- 批量执行能生成 `timing.jsonl`，并能从阶段耗时定位慢点。
- 平台任务状态、统计、下载和权限行为正常。

## 测试数据准备

准备一个压缩包，例如：

```text
616291001.zip
```

压缩包结构。完整改制检查模式下，压缩包可只包含项目资料：

```text
projects/
  改制前BOM/
    BOM-SST26-1101-1.0-备货-006.xlsx
  改制后BOM/
    BOM-SST26-1629-1.0-瑞能-001.xlsx
  改制表/
    改制单-616291001.xlsx
```

另准备关键物料替代表和无关键物料替代表文件，例如：

```text
网页关键物料替代表.xlsx
网页无关键物料替代表.xlsx
```

提交任务时可通过页面的 `关键物料替代表（可选，有更新时上传）`、`无关键物料替代表（可选，有更新时上传）` 单独上传。上传后对应类别保存为全平台最新替代表；后续任务如果不再上传新表，自动复用对应类别的最新版本。

改制表中固定规格型号示例：

```text
上方：P8S150A-61101-1.0
下方：P8S150A-61629-1.0
```

预期匹配：

```text
P8S150A-61101-1.0 -> 1101-1.0 -> BOM-SST26-1101-1.0-备货-006.xlsx
P8S150A-61629-1.0 -> 1629-1.0 -> BOM-SST26-1629-1.0-瑞能-001.xlsx
```

另准备一个只审查替代料是否合规的压缩包，例如：

```text
replacement-only.zip
```

压缩包结构：

```text
projects/
  更新后BOM/
    BOM-SST26-1629-1.0-瑞能-001.xlsx
```

该模式不提供 `改制前BOM` 和 `改制表/改制单`，替代料汇总表仍由页面上传或复用平台最新版本提供。

另准备一个完整改制检查加替代料组齐全检查的压缩包，例如：

```text
projects/
  改制前BOM/
  改制后BOM/
  改制表/
  更新后BOM/
```

其中 `更新后BOM/` 用于额外检查替代料组是否齐全。预期输出根目录包含 `替代料组齐全差异.xlsx`，该工作簿按项目号分 sheet，只显示缺失物料。

另准备一个按日期提交更新 BOM 的压缩包，例如：

```text
projects/
  更新BOM/
    2026-9-7/
      BOM-SST25-0092-1.2-A002匹配关键物料表.xlsx
      BOM-SST25-0093-1.2-A002匹配无关键物料表.xlsx
      BOM-SST25-0094-1.2-A002.xlsx
    2026-9-8/
      ...
```

预期每个日期生成一个 `BOM表改制检查报告-日期.xlsx`；日期报告内每个 BOM 一个 sheet，没有 `匹配关键物料表` 或 `匹配无关键物料表` 关键词的 BOM sheet 写 `备注=跳过`。有关键词的 BOM 同时检查所有真实 BOM sheet 的分层错误、用量与位号数量不一致、位号重复和 BOM 字段缺失。

## 自动化测试

### 1. Skill 脚本测试

命令：

```powershell
python C:\Users\admin\.codex\skills\bom-change-check\scripts\test_check_bom_change.py
```

通过标准：

```text
all tests passed
```

验证点：

- BOM 差异行按同一物料变化合并。
- `IC-烧录程序`/烧录 IC/MCU 程序差异不再只写跳过；应拆成两条 `BOM差异核对`：改制前项目 MCU 写 `删除`，改制后项目 MCU 写 `增加`，备注写 `烧录IC按改制前后MCU拆分显示`。两条 MCU 行必须挨在一起，且 `增加` 行排在 `删除` 行前面。
- 改制单删除项填写位号时，位号和物料代码同等有效；位号在改制后 BOM 已删除则判正常。
- 改制单物料代码空白、写错，或改制前 BOM 已无该位号，但改制后 BOM 也无该位号时，删除核对判正常。
- `改制单核对` 按改制单物料明细逐行输出正常和异常行，不合并多条改制单内容；它是改制单执行清单，不是只列异常，正常增加项也必须显示，例如 `1.02.01.000002 / 增加 / RA54 / 1 / 0603WAJ0000T5E`。
- `改制单核对` 正常行 `备注` 留空，异常行 `备注` 显示具体异常原因。
- 改制单类别/归属包含 `PCBA` 的改制项不输出到 `改制单核对`；它覆盖到的 BOM 差异也不输出到 `BOM差异核对`。
- 先识别改制单 `改制内容` 区域内的软件分界行，例如 `烧录/升级程序`、`烧录程序`、`升级程序`、`PLM取程序`、`工程助理提供软件`；只有分界行以上的改制物品归类为 `产品非电子物料`。不能因为某行缺少物料代码或位号就直接归类；该归类只作为 BOM 对比匹配依据，不直接从改制单输出报告行，也不生成 `产品非电子物料` sheet。分界以上有位号的行按普通电子物料一样对比改制前/后 BOM；分界以上无位号的标签/PE袋/二维码等物料，即使有物料代码，也用规格型号去改制前/后 BOM 对比，未找到时输出到 `BOM差异核对` 并判异常。
- 两文件输入可识别为只审查替代料模式。
- `更新后BOM/` 或 `更新BOM/` 的替代料组齐全检查可识别缺失物料：非 K 关系组按去后缀归组；K 开头关系组跳过；O 列含当前 BOM 客户的物料不要求加入；`取消替代关系物料` 只作为兜底放行，不生成缺失项；日期目录模式按日期生成报告，每个 BOM 一个 sheet，无关键词 BOM 写 `跳过`。
- 替代料单向限制可识别。
- 替代关系先查 `总替代料汇总表`；没匹配时再查 `取消替代关系物料`。
- 替代关系出现在 `取消替代关系物料` 同一行时，替代料核对按正常放行，`替代料关系核对` 不输出该行。
- 两个 sheet 都没有匹配关系时，`替代料关系核对` 备注为 `替代料汇总表未找到该替代关系`。
- `替代料关系核对` 的 `变更内容` 留空，`用量` 从 BOM 行或位号数量兜底。
- 公司物料表目录可以同时提供 `关键物料` 与 `无关键物料` 两个替代表。BOM 文件名含 `关键物料` 时使用关键物料表，含 `无关键物料` 时使用无关键物料表，判断顺序先判断 `无关键物料`。
- 关键物料表只读取 `总替代料汇总表有关键物料` 或 `替代料表匹配工具用关键物料`；无关键物料表只读取 `总替代料汇总表无关键物料` 或 `替代料表匹配工具用无关键物料`。不得同时扫描同一 workbook 内有关键/无关键两个总表 sheet。
- 不同关系组若共享同一个 `类型=主料` 的主料物料代码，应按同一替代族处理，例如 `K187` 与 `T715` 共享主料 `1.03.01.000005`。
- 客户限制 K/O 列规则可识别。
- 输出列顺序符合截图要求。
- 异常和人工复查行保持黄色背景。
- 跳过行进入明细 sheet，且不标黄。
- 除 `BOM差异核对` 和 `改制单核对` 外，正常行不进入明细 sheet；`BOM差异核对` 的正常差异行必须进入明细 sheet，产品非电子物料差异也统一进入 `BOM差异核对`，正常和异常都显示；`改制单核对` 的正常改制单明细必须进入明细 sheet。
- `BOM差异核对` 中被改制单覆盖的位号差异，改制单为增加时备注为 `已按改制单添加`，改制单为删除时备注为 `已按改制单删除`。
- `BOM差异核对` 中被改制单覆盖的行，`变更内容` 直接写 `增加` 或 `删除`，不写笼统的 `变更`。
- 同一位号前后料号不同且需要在 `BOM差异核对` 显示时，不管是否被改制单同时覆盖删除和增加，都拆成两行输出：旧物料写 `删除`，新物料写 `增加`，两行都写清楚料号和规格型号，并且普通换料两行挨在一起。
- `BOM差异核对` 中前后料号存在公司替代关系时不输出该替代料差异；新增的 BOM 替代料行如果和上一行主料存在公司替代关系，也不输出该替代料差异；但改制单明确删除的位号即使对应 BOM 替代料行，也必须输出为正常删除，并用绑定的上一行主料信息显示；差异命中 `取消替代关系物料` 时必须输出，备注为 `取消替代物料，可以忽略`；同一位号旧料换新料时仍拆成 `删除`/`增加` 两行，不是这种换料拆行的替代料显示行才写 `变更内容=替代料`。
- 同一个位号同时出现在 BOM 的主料行和替代料行时，`BOM差异核对` 的位号对比优先使用主料行，不能让下方替代料行覆盖主料行。示例：RA54 同时在主料 `1.02.01.000002 / 0603WAJ0000T5E` 和替代料 `1.02.01.000539 / RS-03000JT` 上，改制单要求增加 RA54 主料时，必须输出主料增加行，不能因为替代料关系有效而隐藏。
- `BOM差异核对` 中被改制单覆盖的增加/删除行，`用量` 列显示改制单填写的数量；其它显示行也要从 BOM 行兜底填写用量，替代料行按位号数量兜底。
- 改制前 BOM 和改制后 BOM 都要做 BOM 自检：自检扫描同一 workbook 内所有符合 BOM 表头的 sheet，不只扫描用于前后差异对比的 `总表` 或第一个 sheet。正常 BOM 行有位号时，`用量` 必须等于位号数量，一个位号对应一个数量；同一个 BOM 的同一个 sheet 内同一位号不能出现在多个非替代料行。发现用量与位号数量不一致或同 sheet 位号重复时，输出到 `BOM差异核对`，判 `异常`，`变更内容` 写 `BOM自检`，备注写清楚 BOM 侧、sheet 和行号。`用量=替代料` 的替代料行允许和上方主料共用位号，不按重复位号异常处理；位号格写有 `配套` 的配套物料行，例如 `配套D5,D6,D7,D8,D9,D10`，允许和 LED/主料共用这些位号，不按重复位号异常处理；不同 sheet 之间不要互相判重复位号。
- 批量运行写入 `project_stage` 和 `report_written` 耗时事件。

## 验收标准

满足以下条件可认为本模块通过验收：

- 页面可提交一个项目压缩包，并可选上传新的替代料汇总表。
- 平台能保存并复用全平台最新替代料汇总表；未上传且无历史最新表时拒绝任务。
- 网页上传或平台保存的最新替代料汇总表优先于项目压缩包内公司物料表。
- 后端能解压固定分类文件夹。
- Codex prompt 明确使用 `$bom-change-check` skill。
- 改制表能按 `归属=保护板1` 和 `归属=保护板2` 的规格型号匹配改制前/后 BOM。
- 删除项能按位号兜底核对，避免物料代码漏写或对不上导致误报。
- 改制单类别/归属包含 `PCBA` 的改制项及对应 BOM 差异不进入报告明细。
- 改制单中软件分界行以上的改制物品只作为产品非电子物料匹配依据，不生成 `产品非电子物料` sheet；有位号的按 BOM 前后差异对比，无位号的标签/PE袋/二维码等物料即使有物料代码也按规格型号对比，结果统一进入 `BOM差异核对`。
- BOM 差异核对中，共享同一主料的跨组替代料关系按正常处理。
- BOM 差异核对中，同一位号同时出现在主料行和替代料行时，优先按主料行判断和输出。
- BOM 自检能扫描同一 workbook 内所有符合 BOM 表头的 sheet，识别用量与位号数量不一致，以及同一 sheet 内非替代料行位号重复；位号格写有 `配套` 的配套物料行与 LED/主料共用位号不报重复；异常输出到 `BOM差异核对`，`变更内容=BOM自检`。
- 更新后 BOM + 公司物料表能进入只审查替代料是否合规模式。
- 同一批次内同时存在关键物料替代表和无关键物料替代表时，能按 BOM 文件名选择正确替代表；`无关键物料` 文件名不会被误判为 `关键物料`。
- 新替代表 workbook 内同时存在有关键/无关键总表 sheet 时，单个 BOM 只扫描选中类型对应的总表 sheet。
- 额外扁平 `更新后BOM/` 能生成 `替代料组齐全差异.xlsx`，只输出缺失物料，按项目号分 sheet；`更新BOM/日期文件夹` 能生成日期报告，每个 BOM 一个 sheet，无关键词 BOM 输出 `跳过`。
- `取消替代关系物料` 中已登记的替代关系按正常处理，不在 `替代料关系核对` 明细中输出。
- `替代料关系核对` 同时查 `总替代料汇总表` 和 `取消替代关系物料`；两个 sheet 都没有时写 `替代料汇总表未找到该替代关系`。
- 每个改制表生成一个带项目号后缀的报告，例如 `BOM表改制检查报告-515451301.xlsx`。
- 同一项目目录不生成、不保留、不统计、不打包无项目号副本 `BOM表改制检查报告.xlsx`。
- 明细列顺序与截图一致：`物料代码、变更内容、位号、用量、规格型号、备注`。
- 除 `BOM差异核对` 和 `改制单核对` 外，明细只显示异常、人工复查和跳过，不显示正常；`BOM差异核对` 显示所有 BOM 对比差异，并包含产品非电子物料 BOM 对比结果；`改制单核对` 显示正常和异常改制单明细，正常行备注留空，异常行备注显示具体异常原因。
- 异常行和人工复查行标黄。
- 下载 zip 中包含输入、报告和日志。
- 任务列表统计与报告 summary 一致。
- 失败原因能定位到缺少文件、匹配不到、匹配不唯一、Codex 执行失败等具体问题。
