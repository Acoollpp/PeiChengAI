# AI Code Review Platform

本上下文描述代码审查任务、报告、问题及用户反馈之间的业务关系。

## Language

**审查任务**：
一次代码审查工作的业务记录，覆盖指定的代码范围并产生一份审查报告。
_Avoid_: 报告任务、反馈任务

**审查报告**：
审查任务产生的完整审查结果，可以包含零个或多个审查问题。
_Avoid_: 审查问题、反馈记录

**审查问题**：
审查报告中一项可以被独立判断和反馈的代码问题，由问题原文及其描述原文共同表达。
_Avoid_: 整份报告反馈、问题序号

**问题原文**：
审查报告中用于识别一项审查问题的原始文字。
_Avoid_: 用户反馈、问题分类

**描述原文**：
审查报告中用于说明一项审查问题的现象、依据或风险的原始文字。
_Avoid_: 反馈说明、处理结果

**问题反馈**：
用户对单个审查问题是否有帮助所作的评价，以及与该评价对应的反馈内容。
_Avoid_: 报告反馈、通用意见反馈

**反馈草稿**：
正式提交前自动保存且仍可编辑的问题反馈；反馈草稿不属于已提交反馈。
_Avoid_: 已提交反馈、正式反馈

**问题评价**：
用户对单个审查问题作出的“有帮助”或“没帮助”判断；尚未作出判断时为“未评价”。
_Avoid_: 报告评价、反馈进度

**反馈说明**：
用户针对单个审查问题填写的可选补充内容。
_Avoid_: 问题描述原文、强制整改说明

**反馈进度**：
一个审查任务中已完成问题反馈的审查问题数量与全部审查问题数量之比。
_Avoid_: 是否有帮助

**反馈完成**：
审查任务中的每个审查问题都已获得“有帮助”或“没帮助”的问题评价；反馈说明不影响完成状态。
_Avoid_: 已填写反馈说明、已查看报告

**已提交反馈**：
用户完成并正式提交的问题反馈记录；提交后不可由用户直接修改。
_Avoid_: 反馈草稿、可编辑反馈

**反馈版 PDF 报告**：
在正式提交反馈后，由原始审查报告与已提交反馈共同生成的最终 PDF；问题反馈显示在对应审查问题下方。
_Avoid_: 原始 Markdown、反馈版 Markdown
