OpenClaw 驱动钉钉协同办公使用指南

本文档用于说明 OpenClaw 驱动钉钉协同办公的访问方式、适用场景和基础使用流程，帮助团队成员快速完成任务跟进、消息整理和办公协同。

一、访问入口

请在公司内网环境下访问系统入口：

http://172.23.17.169:9181/

二、适用场景

  • 钉钉消息内容整理、摘要生成和待办提取。
  • 项目事项跟进、责任人确认和进度提醒。
  • 会议纪要、任务清单和协同记录辅助生成。
  • 跨系统信息查询、整理和办公流程联动。

三、基础使用流程

  1. 打开访问入口，进入 OpenClaw 协同办公页面。
  2. 选择需要处理的钉钉协同场景，例如任务跟进、消息整理或流程处理。
  3. 输入事项背景、处理目标、相关人员和期望输出。
  4. 查看智能体生成的建议、摘要或执行内容。
  5. 确认无误后，再复制到钉钉或业务流程中使用。

四、使用注意事项

  • 重要事项请人工复核后再发送或执行。
  • 涉及客户、合同、人员、财务等敏感信息时，需按公司规范脱敏处理。
  • 如果生成内容与实际业务不一致，应以业务系统和责任人确认为准。
  • 遇到无法处理的异常场景，可联系软件部 AI 对接人反馈。
